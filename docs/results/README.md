# Results

Run results are generated by the pipeline itself, not hand-maintained here. See:

- [`outputs/report.md`](../../outputs/report.md) — the human-readable metrics table, tuning rationale, feature
  justifications, and performance observations from the most recent pipeline run.
- [`outputs/cv_results.json`](../../outputs/cv_results.json) — the same metrics data in machine-readable form.
- [`outputs/split_indices.json`](../../outputs/split_indices.json) — the saved, deterministic train/val/test split.
- [`outputs/baseline_model.joblib`](../../outputs/baseline_model.joblib) — the persisted Logistic Regression pipeline.
- [`outputs/tuned_model.joblib`](../../outputs/tuned_model.joblib) — the persisted Random Forest pipeline.

Regenerate all artifacts with `python scripts/run_pipeline.py` (see [`docs/usage/`](../usage/README.md)).
